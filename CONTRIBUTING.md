# Contributing

Thank you for your interest in contributing to SmartClinic! 🎉

We welcome bug reports, feature requests, documentation improvements, and code contributions.

## How to Contribute

1. Fork this repository.
2. Create a new branch from `develop`.

   ```bash
   git checkout develop
   git checkout -b feature/your-feature-name
   ```

3. Make your changes.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a Pull Request targeting the `develop` branch.

## Pull Request Guidelines

Before submitting a Pull Request, please ensure that:

- Your code follows the existing project style.
- Your changes are focused on a single purpose.
- Documentation is updated when necessary.
- No sensitive information (API keys, secrets, credentials) is included.

## Reporting Issues

If you find a bug or have a feature request, please open a GitHub Issue and provide as much detail as possible.

## Questions

If you have any questions or suggestions, feel free to open an Issue or start a Discussion.

Thank you for helping improve SmartClinic! ❤️
