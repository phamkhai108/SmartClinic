## Quick start

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 — API default: `http://localhost:8000`  
(Set `VITE_API_BASE_URL` in `.env.development` if needed.)

The API must be running first: [doc/setup.md](../doc/setup.md).
