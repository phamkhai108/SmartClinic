# UI: AI Chat

[← UI guides](README.md)

---

## Open Chat

1. Sign in.
2. Open **AI Chat** (or `/app/chat`).
3. Optionally start a **new conversation**.

---

## Ask a question

1. Type in the input at the bottom of the pane.
2. Send.
3. Read the reply as it streams in.
4. If shown, review **Sources** tags under the answer.
