## Adding screenshots

1. Capture the screen for the step you are documenting.  
2. Save under `frontend/doc/images/` with the suggested file name (or edit the `![...](...png)` path).  
3. See [images/README.md](images/README.md) for the full name list.

Until a file exists, the markdown image will appear broken — that slot is waiting for your screenshot.
